# ROSHAN — Full Curriculum Plan (8 Worlds + Brain Gym)

> Every lesson follows STORY → SHOW → DO → CHEER. ONE skill per lesson, ≤ 7 minutes.
> Activity types are engine types (JSON-driven, see doc 05): `tap-select`, `match-slots`,
> `sort-bins`, `tap-sequence`, `catch-falling`, `type-input`, `maze-grid`, `block-canvas`, `build-doc`.
> Every lesson: demo → guided (hint hand) → independent → bonus. Zero failure language. Audio everywhere.

## BRAIN GYM (standalone, runs before main lesson)
- **Daily warm-up (3–5 min):** one rotating puzzle from banks — pattern-next · odd-one-out ·
  sequence-order · memory-grid · sort-it. Rotates by date; mixes 2 previously-learned skills.
- **Adaptive difficulty:** 3 successes in a row → tier up (longer sequences, subtler differences);
  a stumble → drop a tier quietly (never announced as "down").
- **Weekly "Brain Champion":** Friday gauntlet of 5 puzzles; personal-best streak recorded
  in the album. **No leaderboards. No comparing children. Ever.**

## Reward rhythm
- 1–3 stars per activity (bugs-based: 0 bugs = 3★, 1–2 = 2★, 3+ = 1★; completion always ≥ 1★).
- Badge per world (8 total) · sticker per lesson · outfit unlock every N stars
  (12★ cap, 30★ dasti topi, 60★ hero cape) · "Computer Hero" helper ribbon for fast finishers.
